# OpenAI API Fundamentals

Learning the **OpenAI Chat Completions API** from the ground up.

## What's inside

- `INTRODUCTION_TO_OPEN_AI_CHAT_COMPLETIONS_API.ipynb` — the core request/response
  lifecycle: roles (system/user/assistant), messages, models, temperature and other
  sampling controls, and parsing completions in Python.

## Tech stack

Python · OpenAI SDK · Jupyter Notebook

## Setup

```bash
pip install openai jupyter
export OPENAI_API_KEY=your_key_here
jupyter notebook
```
